## ✨ Key Features
* **Interactive AG Grid Dashboard:** High-performance tabular workflow allowing sponsors to filter, review, and select multiple creators using clean multi-row checkboxes.
* **Sticky Action Bar:** Dynamic floating UI controls that trigger instant modal workflows as soon as creators are selected by an investor.
* **Escrow-Backed Bounty Flow:** Simulated integration bridging sponsor funding requests with automated GitHub Issues and payment holds.
* **Responsive Visual Storytelling:** Built around rich architectural moodboards, urban map concepts, and traditional fine-art creative flows.

## 🏗️ Getting Started Locally

To run the project locally on your machine, follow these steps:

```bash
# 1. Clone the repository
git clone [https://github.com/htochko/bounty-donor-point.git](https://github.com/htochko/bounty-donor-point.git)

# 2. Navigate to the project directory
cd bounty-donor-point

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
